# Day 28: Mini ATM Machine

Simulate PIN checking, balance viewing, deposits, and withdrawals.

## Concepts

- functions
- loops
- numeric validation
- state

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python atm.py

Expected result: A menu updates a simulated account balance.

## Extension challenge

Limit the user to three PIN attempts.

## Classroom boundary

Use only fictional values. A real ATM requires hardware security, encryption, audit controls, and regulated banking infrastructure.
