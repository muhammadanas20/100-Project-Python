# Day 13: Student Grade Manager

Collect student scores and calculate a class summary.

## Concepts

- lists
- averages
- min/max
- grade boundaries

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python grades.py

Expected result: Each score receives a letter grade and the class average is shown.

## Extension challenge

Store a name beside each score.
