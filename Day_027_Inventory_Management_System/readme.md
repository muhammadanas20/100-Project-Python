# Day 27: Inventory Management System

Track product quantities and save the inventory as JSON.

## Concepts

- dictionaries
- functions
- JSON
- stock validation

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python inventory.py

Expected result: Stock can be added or sold and persists in inventory.json.

## Extension challenge

Show a low-stock warning below five units.
