# Day 18: Mini To-Do App

Persist tasks in JSON so they survive after the program closes.

## Concepts

- JSON
- lists of dictionaries
- functions
- persistence

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python todo.py

Expected result: Tasks can be added, listed, and marked complete across runs.

## Extension challenge

Add delete and edit commands.
