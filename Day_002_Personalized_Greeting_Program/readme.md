# Day 2: Personalized Greeting Program

Ask for a learner's name and create a greeting just for them.

## Concepts

- input()
- string methods
- f-strings
- validation

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python greeting.py

Expected result: The terminal greets the user with a cleaned, title-cased name.

## Extension challenge

Ask for a favorite hobby and include it in the greeting.
