# Day 22: Bank Account Simulator

Model deposits, withdrawals, and a transaction history with a class.

## Concepts

- classes
- methods
- encapsulation
- validation

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python bank.py

Expected result: A simulated balance changes after valid transactions.

## Extension challenge

Add transfer_to() between two accounts.

## Classroom boundary

This is an in-memory learning simulation, not software for real money or financial records.
