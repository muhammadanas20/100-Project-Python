# Day 4: Number Comparison Tool

Compare two numbers and explain which is larger or whether they match.

## Concepts

- comparison operators
- if/elif/else
- numeric input

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python compare.py

Expected result: A complete comparison sentence appears.

## Extension challenge

Compare three numbers and report the largest.
