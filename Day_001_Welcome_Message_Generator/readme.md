# Day 1: Welcome Message Generator

Build and print a reusable multiline welcome message.

## Concepts

- variables
- strings
- f-strings
- print()

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python welcome.py

Expected result: A formatted five-line welcome message appears in the terminal.
