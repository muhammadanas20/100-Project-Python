# Day 23: Library Management System

Track books, borrowers, and checkouts with small classes.

## Concepts

- classes
- object relationships
- search
- state changes

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python library.py

Expected result: Books can be checked out and returned while availability is tracked.

## Extension challenge

Add due dates and a list of overdue books.
