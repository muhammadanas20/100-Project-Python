# Day 15: Recipe Viewer App

Choose a recipe and display its ingredients and instructions.

## Concepts

- nested dictionaries
- loops
- lookup
- formatted text

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python recipes.py

Expected result: The selected recipe is printed in a readable format.

## Extension challenge

Add prep time and serving size to each recipe.
