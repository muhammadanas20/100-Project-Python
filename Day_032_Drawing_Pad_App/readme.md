# Day 32: Drawing Pad App

Draw freehand lines on a Tkinter canvas with the mouse.

## Concepts

- Canvas
- mouse events
- coordinates
- clear action

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python drawing_pad.py

Expected result: Dragging the mouse draws and the Clear button erases the canvas.

## Extension challenge

Add color and brush-size controls.
