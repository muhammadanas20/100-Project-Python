# Day 21: Wikipedia Article Scraper

Download an allowed Wikipedia page and extract its first paragraphs.

## Concepts

- requests
- BeautifulSoup
- HTML selectors
- responsible scraping

## Setup

Create and activate a virtual environment, then continue below.

Install dependencies:

    python -m pip install -r requirements.txt

## Run

    python wiki_scraper.py

Expected result: The article heading and first three non-empty paragraphs are printed.

## Extension challenge

Save the summary to a text file.

## Classroom boundary

Check terms and robots guidance, identify your script, request slowly, and prefer official APIs.
