# Day 29: Simple GUI App

Open a Tkinter window and respond to a button click.

## Concepts

- Tkinter
- widgets
- callbacks
- event loop

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python gui_app.py

Expected result: A window opens and the label changes when the button is clicked.

## Extension challenge

Add a text box so the greeting uses the student's name.
