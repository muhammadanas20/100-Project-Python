# Day 19: Weather App Using an API

Request current weather by city and display a short summary.

## Concepts

- HTTP requests
- JSON responses
- environment variables
- error handling

## Setup

Create and activate a virtual environment, then continue below.

Install dependencies:

    python -m pip install -r requirements.txt

## Run

    python weather.py

Expected result: The city, temperature, and description are printed.

## Extension challenge

Add humidity and a Fahrenheit option.

## Classroom boundary

Keep API keys in environment variables; never place them in slides or source control.
