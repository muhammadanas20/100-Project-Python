# Day 6: Basic Math Quiz Game

Generate random addition questions and keep score.

## Concepts

- random numbers
- loops
- score tracking
- input conversion

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python math_quiz.py

Expected result: Five questions are asked and a final score is shown.

## Extension challenge

Mix addition, subtraction, and multiplication questions.
