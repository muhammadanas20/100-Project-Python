# Day 5: Countdown Timer

Count backward once per second and announce when time is up.

## Concepts

- for loops
- range()
- time.sleep()
- integer input

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python countdown.py

Expected result: Numbers count down to zero at one-second intervals.

## Extension challenge

Display minutes and seconds as MM:SS.
