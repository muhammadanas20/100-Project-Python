# Day 17: Student Report Generator

Turn a small CSV grade file into a readable text report.

## Concepts

- csv module
- file output
- averages
- structured records

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python report.py

Expected result: A report.txt file is created with one summary per student.

## Extension challenge

Include a letter grade and strongest subject.
