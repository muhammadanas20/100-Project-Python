# Day 8: Contact Book

Store names and phone numbers in a searchable dictionary.

## Concepts

- dictionaries
- CRUD actions
- loops
- key lookup

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python contacts.py

Expected result: Contacts can be added, found, listed, and deleted.

## Extension challenge

Add email addresses using a nested dictionary.
