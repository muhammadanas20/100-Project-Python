# Day 10: Note-Taking App

Append timestamped notes to a text file and read them later.

## Concepts

- file writing
- file reading
- with blocks
- path existence

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python notes.py

Expected result: Notes persist in notes.txt between runs.

## Extension challenge

Add a search command that finds notes containing a keyword.
