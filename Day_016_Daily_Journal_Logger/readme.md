# Day 16: Daily Journal Logger

Save one dated journal entry per run.

## Concepts

- datetime
- append mode
- multiline input
- paths

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python journal.py

Expected result: A dated entry is appended to journal.txt.

## Extension challenge

Add a command that reads entries for a chosen date.
