# Day 24: Employee Management System

Create, list, and update employee records with dataclasses.

## Concepts

- dataclasses
- lists of objects
- search
- updates

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python employees.py

Expected result: Employee records are listed and one salary can be updated.
