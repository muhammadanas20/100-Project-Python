# Day 7: Shopping List App

Add, view, and remove shopping items in a menu-driven program.

## Concepts

- lists
- while loops
- menus
- membership checks

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python shopping_list.py

Expected result: The list changes as menu commands are entered.

## Extension challenge

Prevent blank and duplicate items.
