# Day 30: Click Counter App

Update a GUI label every time a button is clicked.

## Concepts

- mutable state
- callbacks
- Tkinter labels
- button commands

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python counter.py

Expected result: The visible count increases and can be reset.

## Extension challenge

Add a decrement button and prevent negative counts.
