# Day 20: Event Countdown Timer

Calculate the live time remaining until a future event.

## Concepts

- datetime parsing
- timedelta
- loops
- screen refresh

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python event_countdown.py

Expected result: Days, hours, minutes, and seconds update until the event.

## Extension challenge

Give the event a name and display it with the countdown.
