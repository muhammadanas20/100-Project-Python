# Day 25: Animal Sound Simulator

Use a shared method name to demonstrate polymorphism.

## Concepts

- inheritance
- method overriding
- polymorphism
- loops

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python animals.py

Expected result: Different animal objects respond to the same speak() call.

## Extension challenge

Add an animal selected by the user.
