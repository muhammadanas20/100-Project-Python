# Day 31: BMI Calculator

Calculate BMI from height and weight in a small GUI.

## Concepts

- Tkinter Entry
- float conversion
- formula
- validation

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python bmi_gui.py

Expected result: The window displays BMI and a general category.

## Extension challenge

Add optional imperial-unit input.

## Classroom boundary

BMI is a limited screening measure, not an individual diagnosis. Avoid medical conclusions and encourage professional guidance.
