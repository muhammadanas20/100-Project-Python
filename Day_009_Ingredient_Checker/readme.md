# Day 9: Ingredient Checker

Compare available ingredients with a recipe's requirements.

## Concepts

- sets
- set difference
- string splitting
- normalization

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python ingredients.py

Expected result: The program reports whether the recipe can be made and what is missing.

## Extension challenge

Let the user choose from two recipes.
