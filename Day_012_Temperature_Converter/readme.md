# Day 12: Temperature Converter

Convert temperatures between Celsius and Fahrenheit.

## Concepts

- functions
- formulas
- branching
- rounding

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python temperature.py

Expected result: The converted temperature is displayed to one decimal place.

## Extension challenge

Add Kelvin as a third unit.
