# Day 14: Random Password Generator

Create a password with cryptographically strong random characters.

## Concepts

- secrets
- string constants
- comprehensions
- validation

## Setup

Create and activate a virtual environment, then continue below.

This project uses only the Python standard library.

## Run

    python password.py

Expected result: A random password of the requested length is printed.

## Extension challenge

Guarantee lowercase, uppercase, digit, and symbol characters.

## Classroom boundary

Do not display or store real passwords during a public classroom demonstration.
